# O03 authoring helpers — 2026-10-03

Added CLI scaffolds for topics, lessons/dialogues/four exercise types, conversation graphs and recording references. Drafts are created exclusively under `content-source/drafts`, with stable IDs and explicit unreviewed/unknown-rights metadata. No model is called. The optional AI-drafting idea is not a dependency. Structural draft validation is separate from full reviewed-release validation. Promotion is an explicit command that refuses placeholders or unreviewed rights, stages a complete content-version increment, validates the entire release with existing validators and writes the catalog last. Invalid promotion leaves the public tree unchanged; ordinary write failures restore originals. No CMS/backend/library added to runtime.

Validation: `python3 -m unittest discover -s tools -p 'test_author_content.py'` passed three isolated temporary-tree tests covering valid scaffold structure, stable IDs/path rejection, unreviewed no-write behavior, explicit reviewed promotion, coherent versions and retained existing IDs. Promotion tests use clearly labelled artificial review fixtures; they are not shipped language content or content-review evidence.
