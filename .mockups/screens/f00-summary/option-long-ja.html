Goal practised · not mastered

After hearing an explanation about processAsyncResultConfirmationWorkflow, practise restating when the result can be checked and inviting confirmation. The long Japanese example wraps instead of being truncated:

つまり、この処理しょりは非同期ひどうきで実行じっこうされ、結果けっかはあとで確認かくにんできるということですね。

“So this process runs asynchronously, and we can check the result later, right?” This combines the same clarification ideas as the Dialogue; it is a possible restatement, not a memorization target.
